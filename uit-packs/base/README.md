# FireGaze 插件界面简中基础库

这份库面向 FireGaze 的运行时汉化。每个插件内部名对应一份维护记录。团队根据投稿原文、作者发行件和界面上下文编译基础包，包里也保留了可复用的既有 FireGaze 译文。

## 获取数据

| 文件 | 用途 |
| --- | --- |
| [index.json](index.json) | 可应用的基础包。每个内部名只有一个 `library` 包，提供文件名、SHA-256 和三类条目数。 |
| [catalog/targets.json](catalog/targets.json) | 全部支持目标，含投稿号、历史开发名单归属、可用状态和证据。 |
| [bundle/manifest.json](bundle/manifest.json) | 完整离线快照的大小、SHA-256，以及对应索引与目标表的 SHA-256。 |
| [bundle/snapshot.zip](bundle/snapshot.zip) | 一次下载所有基础包、目标状态、索引和目标表。解压后的文件与单包下载逐字节相同。 |

目标表中 `applicable=true` 的记录进入译文合并。其余目标各有一份独立状态文件。`native-zh` 表示已看到作者的中文界面，`native-locale` 表示作者提供中文语言资源。`no-localizable-ui` 表示该发行件的功能没有可译界面正文。`upstream-skip` 沿用主库明确的跳过规则。`needs-source` 记录仍需从实际控件取得原文的插件。

## 客户端复用

首次同步可以下载完整快照，核对长度和 SHA-256，并在临时目录逐包核验。将校验通过的一套文件原子切换为活动版本，保留上一个可用版本。后续按索引中每包 SHA-256 补变更。启动、重载和断网时都从本地已校验的副本读取。

每个包保留 `entries`、`attributes`、`resources`。普通条目和属性保存精确原文，资源同时保留 `Container`、`Key` 和原文。保留格式参数、换行和控件标识。客户端在当前选中插件和来源内，结合当前版本的可见控件、上下文、角色与原文判定候选。目标表中的历史版本和散列用于追溯。

本地按插件保存基础包、用户编辑和跳过记录。用户修订优先于公共译文。已有匹配的原文直接复用；首次出现、内容变化或语义有歧义的可见文本进入补译与审核流程，结果持久保存。库中的条目数只统计译文，实际页面覆盖率由客户端用当前插件版本验证。

目标表的 `translationOriginCounts` 区分本轮团队译文、历史 FireGaze 基础包、既有团队审核和国服术语。`unselectedCandidateRows` 记录此次扫描仍未选入的候选键，其中也可能包含技术字段或不同语言的重复资源。
