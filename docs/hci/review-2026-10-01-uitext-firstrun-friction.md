# 认知摩擦评审 · 插件汉化「首次运行」弹窗

对象：`src/FireGaze/UI/UITextTab.cs` L876–1112 的两张居中弹窗 + 还原图 3 帧 + `Configuration` 默认值。
人物：只想快点把插件变成中文、不懂翻译接口的玩家。无 P0，有 2 个 P1。

## 1. 第一反应

按钮叫「一键汉化」，预期点一下等结果；第一次点却变成答不上来的选择题（大模型／彩云／免费）。顺着默认按主按钮，会被要求离开游戏去注册、建 key。最烦的不是弹窗多，而是第二张出现在已经选过一次之后，只给「仍要使用免费接口／取消」。想摔鼠标的两刻：① 选了免费、点「开始汉化」还被“0.8 秒”警告第二遍；② 按默认主按钮，换来一句“还没填 API key”。

## 2. 逐条摩擦点

**F1｜P1｜默认项和已存设置打架，且必然失败。** 全新用户 `UITextChannel="auto"`（设置里写作「免费·自动」），`OpenFirstRun` 却映射成 0＝大模型——预选的恰是唯一要外部注册的项；没 key 时 `ConfirmFirstRun` 只回一句红字。场景：顺手点「开始汉化」→“还没填大模型 API key”。建议：无 key 时不预选大模型，把免费做成主路径。

**F2｜P1｜第二张弹窗没有退路，取消却已写死选择。** `ConfirmFirstRun` 先落 `UITextChannel=google` + `ChannelChosen=true` 并存盘，才弹免费确认；在第二张点「取消」的人，通道已被永久设为免费，下次点「一键汉化」不再出现选择器；弹窗提到「翻译设置…」却不给按钮。建议：补「改用大模型／打开翻译设置」；通道落盘延后到真正开始翻译。

**F3｜P2｜警告说了两遍，真正该说的没说。** 0.8 秒／限流在选项下方与第二张弹窗几乎逐字重复；玩家真正担心的“会不会把插件搞坏／限流后已翻的会不会丢”两处都没说（页面上有“原文件自动备份、可还原”）。建议合并为一次并补兜底。

**F4｜P2｜没有试连。** key 只做非空校验，填错要等翻译跑起来才在行尾报错。建议开始前发一个最小请求，失败就地提示。

**F5｜P2｜术语与口径漂移。** 同一件事写作“翻译通道／免费接口／通道”；「限流（429）」「MyMemory 每天约 5000 词」是接口单位，和设置窗口的“几千字符/天”“几百条几秒翻完”互相打架。建议统一叫“翻译方式”，只报玩家能感觉到的时间。口径以哪边为准需实机确认。

**F6｜P2｜Esc／点弹窗外＝静默取消。** `BeginPopupModal` 返回 false 即 `pendingStart=null`，行尾不给任何说明，玩家可能以为已经在翻。建议补“已取消，没有开始翻译”。点外部是否真会关闭需实机确认。

（P3 记一笔：「打开完整设置…」会丢掉待办，设置完要回列表重找那个插件再点一次。）

## 3. 只改一处

改 F2：第二张补「改用大模型／打开翻译设置」，并把通道写入挪到真正开始翻译时。它一次消掉两个玩家完全看不见的问题——没有退路的弹窗、取消也照样写进配置。次选是把免费设为默认路径（F1）。
