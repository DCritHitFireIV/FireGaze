# 跨页一致性审计（插件发现 vs 其余四个页签/窗口）

范围：v1.3.0.39 主窗口五个页签（插件汉化 / 简介汉化 / 仓库体检 / 插件安装器 / 插件发现）+ 参与翻译并入后的状态。
证据：`DiscoveryTab*.cs`、`UITextTab.cs`、`TranslateTab.cs`、`RepoAuditTab*.cs`、`InstallerTab.cs`、还原图 `Resources/ui-mockup-discovery.*`。

## 不变量检查

| 区域 | 期望不变量 | 观察到的变体 | 风险 | 建议/处理 |
|---|---|---|---|---|
| 窗口副标题 | 只列当前真实能力 | 仍写「拦住自动刷新」（功能已删） | 用户以为有该功能 | **已修**：汉化 / 体检 / 发现 |
| 页首结构 | 一行说明（+必要灰字），再分隔、再工具行 | 发现页两行说明 + 三行工具区，投稿区又是一块 | 内容被挤到下面 | **已修**：工具栏拆两行、投稿区默认收起 |
| 主操作按钮色 | 主=蓝、正向启用=绿、破坏=红（UiHelpers 约定） | 发现页加库/启用原本是默认灰 | 页面语义不一致 | **已修**：套用 Push*Button |
| 行内按钮命名 | 动词+宾语；同一动作同一个词 | 「添加到我的库」与「加库」并存（旧工作区） | 两种叫法 | **已修**：统一「加库」；旧文案随工作区删除 |
| 状态徽标 | 文本+语义色；不靠颜色单独表意 | 发现页 `[官方]/[已在库]` 为灰字标签，♥ `*` 表未同步 | 可发现性弱 | `*` 加 tooltip；标签保持（与插件汉化 `[官库]/[本地]` 同构） |
| 空/加载/错误态 | 都有明确一行 + 可恢复动作 | 发现页：读取中 / 索引不可用+重试 / 筛选无结果 / 统计不可用 | — | 保持 |
| 搜索行为 | 一个搜索框、即时过滤、大小写不敏感 | 发现页全字段（含译文/作者）；插件汉化按名称；简介汉化按名称 | 行为范围不同（合理差异） | 差异保留；发现页 tooltip 说明范围 |
| Tooltip 用法 | 非常规语义全部有 tooltip | 发现页排序档/♥/推荐/隐藏主库均有 | — | 保持 |
| 随机/排序 | 状态可见、切换即生效 | 随机档原来「换一批」无效（按当前顺序发号） | 功能形同不存在 | **已修**：键值改随机；`换一批`清空重发 |
| 空动作按钮 | 无可执行时不出现 | 「撤回添加」只在最近一次是加库时出现 | — | 保持 |
| 图标含义 | 同形同义 | 发现页 ♥ = 插件点赞；插件汉化「喜欢」是译文包 | 对象不同 | 术语表明确区分 |

## 页面清单

| 页面/组件 | 主要用途 | 主操作 | 状态覆盖 | 备注 |
|---|---|---|---|---|
| 插件汉化 | 第三方/官方插件界面文字汉化 | 一键汉化 / 打开 | 未抽取/已汉化/待写入/失败 | 行内展开详情；右栏多槽按钮 |
| 简介汉化 | 安装器简介翻译、词表更新 | 从 GitHub 更新词表 | 更新中/成功/失败 | 新增 FastDalamudCN 冲突灰字 |
| 仓库体检 | 库链可用性 / 合规 | 开始体检 / 停用 / 删除 | 未检查~可用 + 撤回/备份 | 批量破坏操作有二次确认 |
| 插件安装器 | 列表浏览位置 + 已知问题 | — | — | 只读页 |
| 插件发现 | 全云库插件浏览 | 加库 / 投稿 / 点赞 | 加载/不可用/筛选空/统计降级/未同步/等收录 | 卡片列表 + 行内展开 |

## 合成

- **Top 一致性断裂（均已处理）**：① 副标题过期；② 发现页按钮色不随跨页约定；③ 「加库」多叫法；④ 工具栏密度与其他页的「一行说明 + 一行操作」节奏不符；⑤ 随机的「换一批」名不副实。
- **应写入设计系统的规则**：主/启用/破坏三色按钮约定（已有 `UiHelpers`，发现页现已接入）；页首最多两行文字；工具栏超过一屏就拆行；行高非文本行的列表必须给 clipper 传实测行高。
- **容易混淆的差异**：插件汉化的「喜欢」（译文包）≠ 发现页「点赞」（插件）；两者都保留、各自 tooltip 说明对象。
