# 仓库体检 / 简介汉化 / 插件安装器：skill 复查（2026-10-07）

用户要求：对这三个页签做与「插件汉化 / 插件发现」同套的 skill 复查（design-sense、heuristic-eval、
cognitive-friction、ux-writing 文本审查、consistency-audit、accessibility-precheck、
failure-path-audit、logging-conventions、state-model）。

## 发现与处置

| # | 页 | skill | 问题 | 处置 |
|---|---|---|---|---|
| 1 | 体检 | consistency | 筛选标签「链接失败」与行状态/统计/提示里的「连接失败」不一致（上一轮按用户原话只改了筛选） | 筛选统一回「连接失败」；顺序保持 全部 / 有问题的 / 连接失败 / 已停用 |
| 2 | 体检 | heuristic H4 | 行提示写「建议先**重新体检**」，但按钮一直叫「开始体检」 | 按钮动态改：体检过之后显示「重新体检」 |
| 3 | 体检 | ux-writing | 说明行与扫描完成消息里的括号：「（与卫月同款校验）」「（用时 Xs）」「（可能是网络问题，未勾选）」「（或者都被排除了）」 | 全部改成逗号句/去括号 |
| 4 | 体检 | heuristic H1 / 空态 | 筛选或搜索无结果时表格全空、没有任何说明 | 加空态提示「当前筛选下没有库；换个筛选、或清掉搜索和勾选试试。」 |
| 5 | 体检 | cognitive-friction | 图标下载中「开始体检」被禁用，提示只写「点『停止下载』」——而图标面板已搬到安装器页 | tooltip 改成「图标正在「插件安装器」页下载；先等它跑完，或去那页点「停止下载」」 |
| 6 | 体检 | logging-conventions | 停用 / 删除 / 撤回三个破坏性操作完全没进活动日志 | 全部补 Info / Warning（失败含原因） |
| 7 | 简介汉化 | ux-writing | FastDalamudCN 提示里有括号与「重复/打架」斜杠 | 「会重复或打架。建议…关掉简介翻译；关掉后本插件继续负责简介汉化。」 |
| 8 | 简介汉化 | consistency / 过时信息 | 底部「主库插件的简介汉化请使用 FastDalamudCN（本插件的词表只覆盖第三方插件库）」与顶部提示自相矛盾，且官方条目已进语料、前提过时 | 删除该行 |
| 9 | 简介汉化 | failure-path | 「从 GitHub 更新词表」的后台任务**没有 try**：一旦抛异常 `updateInFlight` 永远为 true → 按钮永久禁用 | try / catch / finally 修复，异常写入状态行与日志 |
| 10 | 简介汉化 | logging-conventions | 启用/关闭汉化、词表更新结果无日志 | 补 Info / Warning |
| 11 | 安装器 | ux-writing | 顶部说明两个「将…」句子绕口 | 改为「下面两项都只影响插件安装器的列表显示，不影响插件仓库的获取与刷新。」 |
| 12 | 安装器 | design-sense / 一致性 | 图标缓存的灰字描述画在复选框**上方**，与同页另两组「开关 → 缩进灰字」不一致 | 灰字挪到「启用图标缓存」下面一行并缩进 |

## 保留（有意不改）

- 「图标下载进行中禁用开始体检」的互斥逻辑保留（两个都是重网络任务；提示已指明去哪儿处理）。
- 简介汉化的后台任务直接写 `updateMessage` 字段（既有风格；字符串/布尔写入原子，读线程拿到旧值最多晚一帧）。
- 体检页一帧 >50ms 的 Warning 日志（定位卡顿用，最多每 5 秒一条）。
