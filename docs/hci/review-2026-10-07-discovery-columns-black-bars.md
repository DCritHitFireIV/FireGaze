# 插件发现：列宽对齐 + 「点赞旁黑条」根因与修复（2026-10-07）

用户报告（附截图请求）：「修改列宽和插件汉化一个列宽；截屏游戏看看点赞那里有很多条黑色的是什么；详情里库链除了复制还有添加到仓库怎么没了；不要出现库链名字，悬停才显示；添加隐藏已在库按钮」。

## 1. 黑条是什么（截图取证）

- 截图方法：游戏在后台时用 `PrintWindow` 抓 FF14 窗口得到白屏（DX11 抓不了），改用
  `AttachThreadInput + SetForegroundWindow` 临时切前台 → `CopyFromScreen` → 立刻切回原前台。
- 像素采样：黑条 = 卡片底色 `#1A1A20`，从 ♥ 所在横坐标（4K x≈2290）开始向右延伸，越过窗口右缘一直盖到游戏画面上。
- **根因**：`DrawRow` 里 `cardMin = ImGui.GetCursorScreenPos()` 取在 `ImGui.TableSetColumnIndex(0)` **之前**——
  `TableNextRow()` 之后光标还停在上一行结束的位置（右列/展开区），于是整行卡片从「上一行的落点」起画；
  且跨列绘制用了 `PushClipRect(..., intersect: false)`（会顶掉窗口裁剪），卡片就直接画到窗口外。
  「点赞那里很多条黑色」= 每行都从 ♥ 开始的一条黑色卡片底，不是任何正常元素。

## 2. 修复（v1.3.0.46）

- **列表结构整体对齐「插件汉化」**（用户点名的参照）：`RowBg | ScrollY | SizingFixedFit`，
  左列 `WidthFixed = 可用宽 − 按钮列 − (滚动条 + 48)`，按钮列按实际按钮宽固定；行尾操作列（♥ + 加库/启用）。
- 删掉自绘卡片（`InsStyle.DrawCard` 调用、`rowHovered`、`detailHeights`、透明 Header 覆盖）——
  自绘卡片是黑条事故的载体，且 ins skill 自己的反模式第 5 条就写了「工具列表不要卡片化」。
- 行点击展开改用与「插件汉化」相同的 `Selectable(SpanAllColumns | AllowItemOverlap)`；
  行内坐标在 `TableSetColumnIndex(0)` **之后**取。
- **详情·库链**：不再常显地址文本；「库链」「复制」「加入自己的库 / 启用 / 已在库」悬停时显示地址 tooltip。
  已在库且已启用的库链显示灰色「已在库」（原来不显示任何按钮，看着像「添加按钮没了」）。
- **新增「隐藏已在库」勾选**（与「隐藏主库」并列）：隐掉仓库已在列表里且已启用的插件（含官方主库），
  只看还能加进库的。

## 4. 跟进：行尾操作右对齐（v1.3.0.47）

用户复看 v1.3.0.46 后：「♥ 的位置是不是有些奇怪，怎么这么前面」——♥ 原来排在操作列的行首，
离行尾还差一整段按钮宽度。改为**整组右对齐**：♥ 固定在最右（与「插件汉化」按钮列同一条右缘），
「加入自己的库 / 启用」排在它左边；无论该行有没有按钮，♥ 都在同一条竖直线上。
截图取证：放大 1920 版截图（`_tmp_glyph.png`）确认那是 ♥ 本体、纵向居中、离右缘约 90 逻辑像素。
