## 逐项证据

| 路径 | 触发 | UI 表现 | 可恢复动作 |
|---|---|---|---|
| 索引不可用 | 卫月改内部字段 | 「读不到卫月的插件库列表…」+ 原因 | 「重试」按钮 |
| 索引为空 | 极早期打开 | 筛选无结果文案 | 自动重试 / 等卫月读完 |
| 统计拉取失败 | 中继不可达/未部署 v8 | 「· 统计暂不可用」+ tooltip | 10 分钟后自动重试；点赞先记本机 |
| 点赞上报失败 | 网络/中继故障 | ♥ 后 `*`，tooltip「未同步」 | 每 15 秒重试一条；重开页面继续 |
| 抓取失败 | 地址不通/404/需登录 | 「打回：取不到这个地址…」 | 输入保留，改后重投 |
| 非仓库文件 | 非数组/JSON 坏 | 「打回：不是卫月能读的仓库文件…」 | 同上 |
| 空仓库 | 空数组 | 「打回：这个文件是空数组…」 | 同上 |
| 无有效条目 | 缺内部名/名字/版本 | 「打回：文件里有 N 条，但没有一条能被卫月识别」 | 同上 |
| 重复投稿 | 云库已有该库链 | 「这条库链已经在云库里了」 | 可选「顺手加到我的库」 |
| 投稿受理失败 | 中继 commit 失败 | 「投稿失败：…（地址没丢，网络好了再点一次）」 | 输入保留 |
| 云端复核失败 | 工作流抓不到/不合格 | 归档 `repo-rejected/` + 通知维护者 | 维护者处理（无玩家身份可回） |
| 加库失败 | 写配置/备份失败 | 状态行给出插件侧错误 | 重试 |
| 撤回添加失败 | 无记录/恢复失败 | 状态行给错因 | —— |
| 状态文件写盘失败 | 磁盘/权限 | **无提示**（静默） | 下次写盘再试；重启丢未同步队列 |

## 关键缺口与建议

- **唯一未处理**：本机状态文件写盘失败静默。低概率；若要补，可在状态行加一次性警告（「本机记录写不进去，点赞重试队列可能会丢」）。
- 网络类失败全部满足「不谎报成功 + 保留输入 + 可重试」三条。
