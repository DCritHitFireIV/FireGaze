# FireGaze UI 术语表（插件发现 & 与全插件对齐）

范围：主窗口五个页签，重点覆盖 2026-10-06 新增的「插件发现」。依据：`DiscoveryTab*.cs` 实际文案 + 还原图 `Resources/ui-mockup-discovery.*`。

## 1. 规范术语（Canonical glossary）

| 术语 | 类型 | 准确含义 | 用在哪 | 备注 |
|---|---|---|---|---|
| 插件发现 | 名词（页签） | 展示云端插件库全部插件的页签 | 主窗口第五页签 | 不要叫「插件市场/插件商店」 |
| 云库 | 名词 | 维护者流水线维护的云端插件语料（词表 + 库链） | 投稿区、tooltip | 不再对玩家说「云端语料/词表」 |
| 库链 | 名词 | 插件仓库的 pluginmaster.json / repo.json 地址 | 来源库列、展开区 | 不叫「仓库地址/库地址」 |
| 官方主库 | 名词 | 卫月官方主库（Dip17 分发） | 行标签、tooltip | 标签可简写 `[官方]`，说明文字一律写全称 |
| 加库 | 动词 | 把一条库链加进**本机**的第三方插件列表 | 行尾按钮、展开区 | 与「投稿」严格区分 |
| 启用 | 动词 | 让本机已停用的库恢复启用 | 行尾/展开区按钮 | 不改链接 |
| 撤回添加 | 动词 | 撤销最近一次「加库」 | 筛选行小按钮 | 只在最近一次操作是加库时出现 |
| 投稿 | 动词 | 把一条库链发到**云库** | 投稿区按钮 | 与「加库」严格区分 |
| 收录 | 动词 | 云端工作流把投稿并入云库 | 投稿结果、等收录 | 流程词，不用「入库/上架」 |
| 等收录 | 状态 | 已投稿但词表还没带上这条库链 | 投稿区计数行 | 对应 `SubmittedRepos − 云库已有` |
| 一行简介 | 名词 | 仓库清单的 Punchline | 展开区、搜索说明 | 不写「标语/副标题」 |
| 详情 | 名词 | 仓库清单的 Description | 展开区、搜索说明 | — |
| 内部名 | 名词 | InternalName | 展开区 | — |
| 最后更新 | 名词 | 清单里的 LastUpdate（北京时间显示） | 元信息行、展开区 | 归一化到 unix 秒 |
| 推荐 | 名词 | 玩家从发现页把该插件所在库加进自己库的累计次数 | 元信息行、展开区、排序档 | tooltip 要写全「从云端加进自己库」 |
| 点赞 | 名词/动词 | 对**插件**的一周一次匿名投票（♥） | 行尾按钮、排序档 | 数字格式「周/总」 |
| 喜欢 | 名词/动词 | 对**译文包**的点赞（插件汉化页） | 插件汉化页 | 与「点赞」是不同对象，刻意分开 |
| 换一批 | 动词 | 随机排序下重新洗牌 | 排序行按钮 | 只在随机档出现 |
| 隐藏主库 | 过滤器 | 不显示官方主库条目 | 筛选行 | — |
| 连着已停用的库 | 过滤器 | 连本机已停用的库一并显示 | 筛选行 | 用户 2026-09-21 定的原句 |

## 2. 应避免的术语（Terms to avoid）

| 不要用 | 改用 | 原因 |
|---|---|---|
| 云端语料 | 云库 | 开发术语，玩家读不懂 |
| 拦住自动刷新 | （删除） | 功能 2026-09-17 已移除 |
| 这条件库 | 这条库链 | 「条件库」歧义（已修） |
| ♥ 一周一个插件一次 | 每个插件每周可点赞一次 | 「一次」指代不明 |
| 点赞/推荐统计暂时拉不到，先按插件名排 | 统计暂不可用（详情进 tooltip） | 长句挤爆工具栏 |
| 添加到我的库 | 加库 | 同一动作两种叫法；页内统一「加库」 |
| 入库 / 上架 | 收录 | 云端流程统一叫收录 |

## 3. 状态模型（Status vocabulary）

| 状态 | 含义 | 进入 | 退出 |
|---|---|---|---|
| 未加入 | 库链不在本机列表 | — | 加库/启用成功 |
| 已启用 | 库链在本机且启用 | 加库/启用成功 | 在仓库体检停用 |
| 已停用 | 库链在本机但停用 | 仓库体检停用 | 启用成功 |
| 官方 | 来自官方主库 | — | — |
| 未赞（本周） | 本周没给该插件点过赞 | 新的一周 | 点赞 |
| 本周已赞 | 本周已点过一次 | 点赞成功（本地先记） | 下周一 00:00（北京时间） |
| 未同步 | 点赞/加库上报还没成功（`*`） | 上报失败 | 重试成功 |
| 未投稿 / 等收录 / 已收录 | 投稿流程三态 | 投稿成功 | 词表带上该库链 |
| 统计暂不可用 | 中继统计拉不到 | 拉取失败 | 下次拉取成功（10 分钟节流） |

## 4. 动作词汇（Action vocabulary）

- 行内动作：**加库**（蓝，主操作）→ **启用**（绿）→ **撤回添加**（小按钮，仅可撤时出现）
- 数据动作：**复制**（库链）、**在浏览器打开**
- 社交动作：**点赞**（插件，一周一次）；**喜欢**（译文包，插件汉化页）
- 投稿动作：**投稿**（发往云库）、**顺手加到我的库**（勾选项）
- 列表动作：**换一批**（随机档）、**隐藏主库**、**连着已停用的库**、**排序**

## 5. 命名问题与建议

- 「推荐」是自造指标名：保留（用户点名的排序档名），但所有出现处都必须配一句「从云端加进自己库的次数」，避免被理解成人工推荐。
- 「喜欢」与「点赞」是两套体系（译文包 / 插件）：分属两个页签、互不相干；tooltip 各自说清对象。
- 排序档名字长（「每周点赞排行」）：下拉框宽度按最宽档名实算，不写死。

## 合成

- **最伤人的五处术语不一致**：①「拦住自动刷新」过期（已删）；②「云端语料」对玩家不可读（已改「云库」）；③「这条件库」歧义（已改）；④ 加库的两种叫法（已统一「加库」）；⑤ 统计失败的冗长句（已缩）。
- **易混概念**：加库（本机）vs 投稿（云端）；喜欢（译文包）vs 点赞（插件）；推荐（加库次数）vs 点赞数。
- **优先固定**：云库 / 库链 / 加库 / 投稿 / 收录 / 点赞 / 推荐——这七个词在后续版本里不得再出现同义变体。
