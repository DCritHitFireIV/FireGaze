# 启发式评估（盲评）— FireGaze「插件汉化」v3 还原图（2026-10-02）

> **评审方式**：fresh-context `reviewer` 子代理盲评。只读还原图（PNG + HTML）与 `heuristic-eval/SKILL.md`；未读 `src/` 实现与 `docs/hci/` 旧评审。
> **评审对象**：`Resources/ui-mockup-uitext-v3-list.{png,html}`（帧 1 列表 / 帧 2 展开详情）、`Resources/ui-mockup-uitext-v3-windows.{png,html}`（帧 3 编辑校对 / 帧 4 翻译设置）。
> **口径**：P0 = 阻断或严重误导（0–4 中的 4）；P1 = 发布前必须改（3）；P2 = 应改（2）；P3 = 打磨（1）。
> **局限**：悬停 / 滚动 / 键盘 / 真实字号与窗口尺寸行为无法从静态图验证，统一标注「需实机确认」。

## ① 一句话总评

v3 在信息完备度上已经“够用且诚实”（状态、备份、通道、隐私、限流都写明了），但存在两类系统性问题：**同一件事在不同界面有 2–3 套说法（一键汉化 / 翻译未翻+写入并重载 / 下载并应用）**，以及**状态与图例、指引与控件、声明与按钮之间存在多处自相矛盾**——用户不会“看不懂功能”，而是会在关键几步上“以为自己已经完成了”。

## ③ Top 5

1. **L1 — 失败行上的「一键上传」**（公开、不可逆、无范围说明，且此刻上传的是从未应用过的译文）。
2. **E11 —「一键汉化」vs「翻译未翻 + 写入并重载」的心智模型冲突**（跨列表/编辑器）。
3. **D2 —「下载并应用」与“下载后点「一键汉化」”自相矛盾**。
4. **S1 —“自动保存”与「保存 key」按钮并存**（可能静默丢 key）。
5. **E1 — 图例与实际 6 种符号不符/不全，且语义错位**。

紧随：**D1**（中文插件行指引的控件不存在）、**L2**（失败恢复路径过长）。
