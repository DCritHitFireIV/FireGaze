# 插件发现 — HCI 总结（hci-summary）

## 背景回顾

2026-10-06「参与翻译」并入第五页签「插件发现」：整座云端词表（含官方主库）+ 六档排序 + 点赞（插件、每周一次）+ 库链投稿 + 加库；用户同日纠正「要插件汉化那种样式、翻译贡献全退场」。当天完成卡片化改造、列宽修复、LastUpdate/随机两个 bug 修复与 11 项技能评审。版本 v1.3.0.39，未推送。

## Top 5 困惑风险

1. **三个动词并排**：加库（本机）/ 投稿（云库）/ 点赞（社交）——靠术语与位置区分，首次用户仍需读 tooltip。
2. **♥ 数字顺序**（周/总）——tooltip 才说清。
3. **「推荐」是自造词**——容易被当成人工推荐。
4. **加库粒度是库不是插件**——按钮长在插件行上，要用「这条库」文案与 `[已在库]` 消歧。
5. **官方插件无加库按钮**——需要展开区一句话解释「本来就有」。

## Top 5 应固化的设计不变量

1. 主操作=蓝、启用=绿、破坏=红（`UiHelpers.Push*Button`），发现页必须继续接。
2. 行高非文本行的列表，`ImGuiListClipper` 必须传实测行高。
3. 中继类上报失败永远不谎报成功：本地先记、`*` 标记、后台重试。
4. 云端概念对玩家只说两个词：**云库**（内容）与**收录**（流程）。
5. 页首最多两行文字；工具栏一屏放不下就拆行。

## Top 5 实现优先级

1. 实机验证卡片间距/字号（当前为按 1.0 缩放的估算值）。
2. 云端部署：worker v8 + repo-inbox / plugin-stats 工作流（等推送指令）——否则点赞/投稿只有本地一半。
3. 官方条目译文补齐（460 名 / 412 简介，跑一次 translate 工作流）。
4. 图标策略再评估（可见行限速下载 vs 只显示首字母块）。
5. 键盘可达性（tooltip 信息的替代呈现，ImGui 限制下的最小方案）。

## 开放假设与未知

- 玩家真实使用中会不会用「随机」与研究「每周赞」——无数据，待实机。
- 投稿量级未知：不限次不限条是用户定的，若出现刷库再上 blocklist/预算。
- 中继时钟与客户端时钟不一致时的周界边界（已用双标签容错，未实测）。
- 发现页的「推荐」是否会与安装器的下载数混淆——术语表已分开，待观察。
