# 独立 HCI 评审：「插件汉化」首次一键汉化弹窗流程

评审对象：还原图 `Resources/ui-mockup-uitext-firstrun.html`（3 帧）+ 实现 `src/FireGaze/UI/UITextTab.cs:876-1112`（含 `ConfirmFirstRun` / `DrawSecretRow`），并对照 `UITextSettingsWindow.cs`。方法：Nielsen 十项启发式 + 严重度分级（P0=4 阻塞 / P1=3 必须改 / P2=2 应该改 / P3=1 可以考虑）。**只依据读到的材料，未使用任何用户反馈。**

## 1. 总体判断

**能用，骨架正确**：把「选通道」从设置里挪到动作发生的那一刻、默认选中推荐项、选免费时再确认、且只确认一次（`UITextFreeWarned`）——这是对的方向，比让用户先猜再失败好得多。

**最大风险不是文案，而是状态写入的时机**：程序在用户按下第二张弹窗的按钮**之前**就已经把通道改成免费并 `SaveConfig()`（P1-2）；两张弹窗还共用同一个密钥输入缓冲（P1-1）。两者都属于「用户没同意，状态已经变了」的静默变更，比多等几分钟更难被发现。其次是**信息错位**：慢（0.8 秒/条）讲了三遍，真正会让玩家吃惊的后果（点下去就会改写插件 DLL 并重载该插件）一次都没讲。

## 2. 逐条问题

| # | 严重度 | 现象 / 证据 | 建议怎么改 |
|---|---|---|---|
| 1 | P1 | 大模型与彩云两行都绑定同一个 `firstRunSecretInput`；切换单选不清空。在「大模型」下粘贴 key → 改选彩云 → 点「开始汉化」，`ConfirmFirstRun` 会把这段值 `ProtectToBase64` 存成**彩云 token**（反向亦然）；`OpenFirstRun` 才清空，重开选择器时旧值仍在框里 | 每通道独立缓冲（或切换单选即清空），只取当前选中通道的输入 |
| 2 | P1 | `ConfirmFirstRun` 在弹免费确认**之前**已执行 `config.UITextChannel = "google"` + `UITextChannelChosen = true` + `SaveConfig()`。用户在「免费接口会慢很多」按「取消」→ 通道已静默变成免费，行内「译文来源：」随之改变；且 `ChannelChosen` 已为真，**下一次点「一键汉化」不再出现选择器、只弹免费警告** | 通道写入延后到第二张弹窗点「仍要使用」之后；或取消时回滚到进入前的通道 |

| 4 | P2 | 同一个窗口三种叫法：正文「翻译设置…」、主按钮「打开完整设置…」、失败提示按钮「打开翻译设置」，窗口标题是「翻译设置」。「完整设置」还暗示存在一个不完整的设置 | 统一为「翻译设置…」 |
| 5 | P2 | 第二张弹窗首句与帧 2 选项下方的橙字**逐字重复**（「每个词条约 0.8 秒…」）；两张都没给具体量级，而行内其实已有候选/未翻译条数可用 | 第一张只留选项级一句话；第二张换成具体估计（条数 × 0.8 秒，数量级即可）；并在此处直接给「改用大模型」出口（现在要先取消、再找插件、重选、再确认，4 步） |
| 6 | P2 | 第二张弹窗没说**哪个插件**、也没说用的是哪个通道。`IsFreeChannel` 把 `"auto"` 也算免费，而「翻译设置」里 `auto`（免费·自动）是默认项之一 → 用户可能看到一张讲 Google/MyMemory 的弹窗，却并不知道自己被判定为免费通道 | 标题带插件名与通道名（如「免费接口会慢很多 — ×××插件 / Google 免 key」） |
| 7 | P2 | 两张弹窗均未提真正后果：点下「开始汉化」会**立刻翻译→改写插件 DLL→自动重载该插件**。该提示只存在于主界面工具条（「插件在跑任务时先停一下，重载会打断它」），而它在遮罩后面 | 弹窗里补一行灰字写明动作后果 |
| 8 | P2 | 弹窗里第一次要求粘贴 API key，却缺设置窗口已有的两条关键信息：「key 只存本机（DPAPI 加密），不会随任何提交上传」与「测试连接」（`TestChannel()` 已实现）。加上 `ImGuiInputTextFlags.Password`，键错只能在翻译失败后才发现（提示字段 `firstRunError`） | 弹窗内加一句存储说明 + 复用「测试连接」 |

## 3. 做对的地方（具体）

- **渐进披露**：只有选中某项才展开其细节（`if (this.firstRunChoice == 0)`），三个通道的信息不铺满屏，弹窗保持紧凑。
- **默认给推荐项**，不替用户选最慢的免费通道；`OpenFirstRun` 还会按已存通道回填单选（`"caiyun" => 1, "google" or "mymemory" => 2`），不是每次都退回 LLM。
- **警告就地出现**（帧 2 橙字紧贴选项），且选项标签本身已写「很慢、随时可能被限流」——不需要用户记住或去别处找。
- **只确认一次**且 Esc/点外面即取消（代码注释明写「下次点『一键汉化』再问」），确认不会退化成骚扰。
- **弹窗给的是出路不是恐吓**：「等不了就改用大模型或彩云小译；『翻译设置…』里随时能改。」失败路径同样留了可点的「打开翻译设置」。
- 弹窗标题用 `###` 隔离 ID（`"选择翻译方式###UITextFirstRun"`），显示名干净；两张弹窗的可见文案与还原图**逐字一致**。
