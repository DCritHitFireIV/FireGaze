# 灰名单（Ambiguous）插件注解 — 2026-10-03

> 基于全量探针（本机 190 个已装插件）。**灰名单 ≥10 的 52 个**，其中 ≥50 的 20 个；不汉化名单内的插件已排除。

## 灰名单是什么、怎么翻

- **灰名单 = 默认不翻的「双身份」字符串**：既像界面文字，又可能被插件当查表 key / 参与比较 / 当文件路径或 JSON 键用。翻错了轻则不显示、重则坏功能，所以默认拦下。
- **单插件翻**：插件汉化 → 该插件行「编辑校对」→ 底部「**连灰名单一起翻译 (N)**」（N = 该插件还没翻的灰名单条数）。
- **全局开关**：翻译设置 →「批量翻译时连灰名单一起翻」（会弹确认框）。
- 翻完一定**抽查界面**；出问题的条目在编辑器里清空译文/标不翻，重新应用即可（有备份可还原）。
- **内置中文**列 = 该插件 DLL 自带的简体中文文本条数（在补丁前原件上数；≥60 条基本可认为是汉化分支或自带官方中文）。

## 结论速览

- **建议勾（界面文案为主，收益大）**：Aetherphone、Questionable、XivMediaPlayer、AcquisitionDate、Autofate。
- **可勾·注意（能补全，但会覆盖插件自带中文/有少量键名）**：InventoryTools、Brio、WrathCombo、CurrencySpender、Collections、ChilledLeves、TouristMod、Glamaholic、AllaganItemSearch。
- **别勾（内部标识/路径/协议为主，翻了白干或有害）**：其余多数；尤其别碰 Phantom、ai02、Beastmaster、GatherBuddyReborn 这类「比较项是别的插件名（IPC）」与 AetherDraw 的图片路径。
- **52 个里 20 个安装版自带中文**（汉化分支/官方中文；另有 WrathCombo / SubmarineTracker / AutoDuty 的译文在卫星程序集或本地化文件里）——它们的灰名单多是本地化 key，勾了会以机翻盖官方译，建议只在「某处确实还显示英文」时用编辑器单条补。
- 标签：**建议勾** = 收益大风险低；**可勾·注意** = 有覆盖/少量键名代价；**慎勾** = 混合，建议编辑器挑着翻；**低优先** = 量小或可有可无；**别勾** = 内部标识/路径/协议为主。

## 备注（两条要留意的）

1. **安装版汉化分支，但内部名不在不汉化名单**：ICE、BossModReborn、Artisan、InventoryTools、Lifestream、Phantom、ai02、Beastmaster、DalamudACT、lccTools、Pawprint、Yourcraft —— 名单里写的是 ICECN / BossModRebornCN / InventoryToolsCN 这种带 CN 的名字，运行时按内部名匹配不到，所以 FireGaze 目前不会跳过它们。要不要补名单（或改成看仓库/元数据判定）等你拍板；本轮清单已按「自带中文」标注给出建议。
2. **数字口径**：灰名单数来自探针全量抽取；编辑器按钮上的 (N) 以当前包/重新抽取结果为准（会把已翻、已跳过的除去），可能与本表有少量出入。
